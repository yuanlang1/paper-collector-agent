## 目标

根据用户提供的研究主题和约束，完成可信的论文检索；除非用户明确只要检索结果，否则使任务达到 `RAG-ready`，供后续问答或综述使用。

## 工作流

1. 从当前请求中提取主题、时间范围、论文类型、数量、语言和筛选标准；不要补造缺失的限制条件。
2. 对新的检索任务调用 `paper_search_agent`。只使用其真实结果，不把说明性回答或已有任务查询当作新的检索任务。
3. 从结果中取得有效任务 ID。若没有任务 ID 或检索失败，如实说明，停止依赖该任务的后续步骤。
4. 若用户未明确要求“只检索、不建立索引”，先用 `get_task_rag_status` 检查任务状态，再调用 `task_indexing_agent`。等待明确的成功终态，并再次确认任务为 `RAG-ready`。
5. 输出与请求相关的检索范围、筛选结果、真实任务 ID 和最终索引状态；不要把“检索完成”表述为“已可用于 RAG”。

## 边界

- `search_web` 可以补充实时网页信息，但不能替代完整论文检索。
- 论文、任务 ID、索引状态和数量均必须来自真实工具结果。
- 若用户明确只要检索结果，跳过索引，并清楚说明该任务尚不能用于 RAG 综述。
